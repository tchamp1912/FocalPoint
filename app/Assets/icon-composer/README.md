# FocalPoint Icon Composer layers

These SVGs are all authored on the same 1024×1024 pt canvas. Import them into Icon Composer in numeric order:

1. `01-background.svg` — black background
2. `02-lens.svg` — translucent lens foreground
3. `03-rays.svg` — RGB ray paths
4. `04-focus.svg` — focal point

The visible mark is intentionally centered and fills most of the canvas; do not crop or resize individual layers before importing. In Icon Composer, use the lens layer for refraction/translucency and the ray layer as the foreground content passing through it.
